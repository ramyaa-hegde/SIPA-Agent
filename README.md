# Search Intelligence Portfolio Agent (SIPA)

## Overview

Search Intelligence Portfolio Agent (SIPA) is my personal AI agent designed to transform technical projects into recruiter-ready portfolio assets.

Instead of manually writing documentation for every project, SIPA analyzes project artifacts such as GitHub repositories, notebooks, README files, metrics, and technical notes and generates:

* Technical case studies
* Resume bullet points
* Portfolio project descriptions
* LinkedIn-ready summaries
* Interview preparation notes
* Skills extracted from the project
* Suggested portfolio improvements

## Purpose

The goal of SIPA is to help me maintain a consistent, evidence-based engineering portfolio as I transition from **Senior Operations Analyst** to **AI/ML Engineer** and **Data Scientist**.

## Current MVP

This repository contains the first working version of SIPA built during the FlyRank AI Fluency track.

The MVP focuses on analyzing a single technical project end-to-end and producing recruiter-ready documentation from real project artifacts.

## Technology

* GitHub
* GitHub repositories as project inputs
* Claude / ChatGPT as the reasoning engine
* Prompt-driven workflow architecture

## Long-Term Vision

SIPA will evolve into a personal career operating system capable of documenting machine learning projects, analytics work, automation systems, university projects, and future engineering work while keeping my resume, portfolio, and professional profiles synchronized.
